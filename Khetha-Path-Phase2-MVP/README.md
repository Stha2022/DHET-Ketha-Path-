# Khetha Path — GovTech 2026 Phase 2 MVP

## Run
1. Extract into `C:\xampp\htdocs\Khetha-Path-Phase2`
2. Start Apache in XAMPP.
3. Open `http://localhost/Khetha-Path-Phase2/`
4. MySQL is not required for this demo yet.
5. Optional: import `database/khetha_path.sql` in phpMyAdmin for the Phase 3 data layer.

## Demo journey
Home → enter name → conversational onboarding → assessment → results → My Path → What If?
Then open `ask.html` to demo Ask Khetha.

## Important
AI responses in `ask.php` are intentionally prototype responses. They are not presented as live NCAP/DHET answers. Production integration should ground responses in approved NCAP/DHET content and show sources.
