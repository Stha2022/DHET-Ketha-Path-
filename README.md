# Khetha Path — GovTech 2026 Phase 2 MVP

## Run
1. Extract into `C:\xampp\htdocs\Khetha-Path-Phase2`
2. Start Apache in XAMPP.
3. Open `http://localhost/Khetha-Path-Phase2/`
4. MySQL is not required for this demo yet.
5. Optional: import `database/khetha_path.sql` in phpMyAdmin for the Phase 3 data layer.

## Demo journey
Home → enter name → conversational onboarding → Subject Choice hub → Interests / Career Abilities / Employability Skills questionnaires → per-questionnaire report → combined study-field report → contact a Career Advisor.

## Important
Institution/qualification names shown in the Subject Choice reports are mock placeholder data for this prototype, not a live NCAP listing. Production integration should ground these in approved NCAP/DHET content and show sources.
